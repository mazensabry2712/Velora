# Velora Architecture Roadmap

The architecture migration remains incremental and backward-compatible.

1. Application use cases for core writes.
2. Domain contracts for cross-layer dependencies.
3. Infrastructure adapters for framework/provider details.
4. Explicit central/tenant persistence boundaries.
5. Event-driven non-critical side effects.
6. Architecture and tenant-isolation tests.
7. Remove legacy paths only after regression coverage proves equivalence.
