# 🧪 كيفية اختبار إجراءات المواعيد والطابور

تم إنشاء ملفات اختبار شاملة للتحقق من تكامل نظام المواعيد مع الطابور.

---

## 📁 ملفات الاختبار

### 1. **دليل الاختبار اليدوي** 📋
**الملف:** `APPOINTMENT_TESTING_GUIDE.md`

**الوصف:** دليل شامل خطوة بخطوة لاختبار كل وظيفة يدوياً

**كيفية الاستخدام:**
1. افتح الملف `APPOINTMENT_TESTING_GUIDE.md`
2. اتبع الخطوات بالترتيب
3. ضع علامة ✅ على كل اختبار ناجح

**يغطي:**
- ✅ عرض صفحة المواعيد
- ✅ إنشاء موعد جديد (يُضاف للطابور تلقائياً)
- ✅ تحديث حالة الموعد والتأثير على الطابور
- ✅ إضافة/إزالة موعد من الطابور يدوياً
- ✅ فلترة المواعيد حسب حالة الطابور
- ✅ عرض معلومات الطابور
- ✅ الحذف التسلسلي (Cascade)

---

### 2. **سكريبت الاختبار السريع** ⚡
**الملف:** `public/js/appointment-test.js`

**الوصف:** سكريبت JavaScript للاختبار السريع من Browser Console

**كيفية الاستخدام:**

#### الطريقة 1: من Console مباشرة
```javascript
// 1. افتح صفحة المواعيد
// http://localhost/admin/appointments

// 2. افتح Developer Tools (F12)

// 3. انسخ والصق محتوى الملف في Console

// 4. استخدم الدوال:
testAddToQueue(1)                      // إضافة الموعد #1 للطابور
testRemoveFromQueue(1)                 // إزالة الموعد #1 من الطابور
testUpdateStatus(1, "confirmed")       // تحديث حالة الموعد #1
getAppointmentInfo(1)                  // عرض معلومات الموعد #1
testFullScenario(1)                    // اختبار سيناريو كامل
```

#### الطريقة 2: تضمينه في الصفحة
أضف في `resources/views/admin/appointments/index.blade.php` قبل `</body>`:
```html
<script src="{{ asset('js/appointment-test.js') }}"></script>
```

**الدوال المتاحة:**
- `testAddToQueue(id)` - اختبار إضافة موعد للطابور
- `testRemoveFromQueue(id)` - اختبار إزالة موعد من الطابور  
- `testUpdateStatus(id, status)` - اختبار تحديث حالة الموعد
- `getAppointmentInfo(id)` - عرض معلومات الموعد
- `testFullScenario(id)` - اختبار سيناريو كامل تلقائياً

## 🚀 اختبار سريع (5 دقائق)

### الخطوة 1: التحقق من الواجهة
1. افتح `http://localhost/admin/appointments`
2. تحقق من وجود عمود "رقم الطابور"
3. تحقق من وجود عمود "الإجراءات"
4. تحقق من وجود أزرار "إضافة" و "إزالة"

### الخطوة 2: اختبار الإضافة
1. ابحث عن موعد **بدون** رقم طابور
2. اضغط زر "إضافة" الأرجواني
3. يجب أن يظهر رقم طابور
4. الزر يتحول إلى "إزالة" أحمر

### الخطوة 3: اختبار الإزالة
1. اختر نفس الموعد (الآن له رقم طابور)
2. اضغط زر "إزالة" الأحمر
3. وافق على رسالة التأكيد
4. رقم الطابور يختفي
5. الزر يعود إلى "إضافة" أرجواني

### الخطوة 4: اختبار التكامل
1. أنشئ موعد جديد
2. يجب أن يُضاف للطابور تلقائياً
3. غير حالة الموعد إلى "مكتمل"
4. حالة الطابور تصبح "مكتمل" أيضاً

## 🎯 اختبار متقدم (Browser Console)

افتح Console واكتب:

```javascript
// 1. تحميل سكريپت الاختبار
fetch('/js/appointment-test.js')
  .then(r => r.text())
  .then(eval)

// 2. بعد التحميل، اختبر موعد معين (مثلاً #1)
testFullScenario(1)

// هذا سيقوم بـ:
// - إضافة الموعد للطابور
// - تحديث الحالة إلى "مؤكد"
// - تحديث الحالة إلى "مكتمل"
// - التحقق من تزامن حالة الطابور
```

## 📊 التحقق من النتائج

### ما يجب أن يعمل:
✅ إضافة موعد للطابور من زر "إضافة"  
✅ إزالة موعد من الطابور من زر "إزالة"  
✅ عند إلغاء الموعد → الطابور يصبح "متجاوز"  
✅ عند إكمال الموعد → الطابور يصبح "مكتمل"  
✅ عند تأكيد الموعد → الطابور يبقى "في الانتظار"  
✅ فلترة المواعيد حسب حالة الطابور  
✅ إحصائيات "في الطابور" تتحدث  
✅ حذف موعد يحذف الطابور معه (CASCADE)  

### ما يجب أن **لا** يحدث:
❌ لا يمكن إضافة موعد للطابور مرتين  
❌ لا يمكن إزالة موعد غير موجود في الطابور  
❌ لا تظهر أخطاء في Console  
❌ الصفحة لا "تتجمد"

## 🐛 الأخطاء الشائعة

### خطأ: "Appointment already in queue"
**السبب:** المحاولة إضافة موعد موجود بالفعل في الطابور  
**الحل:** هذا طبيعي - الزر يجب أن يتحول إلى "إزالة"

### خطأ: "Appointment not in queue"
**السبب:** المحاولة إزالة موعد غير موجود في الطابور  
**الحل:** هذا طبيعي - الزر يجب أن يتحول إلى "إضافة"

### لا يحدث شيء عند الضغط
**السبب:** قد يكون هناك خطأ JavaScript  
**الحل:** افتح Console وابحث عن الأخطاء الحمراء

### الصفحة لا تتحدث
**السبب:** JavaScript مضاف `location.reload()` بعد ثانية  
**الحل:** انتظر قليلاً أو حدّث يدوياً
